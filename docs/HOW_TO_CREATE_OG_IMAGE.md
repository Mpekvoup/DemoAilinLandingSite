# 🖼️ Инструкция: Как создать og-image.jpg

## Что это?

**og-image.jpg** - это превью-картинка, которая показывается когда вы делитесь ссылкой на сайт в соцсетях (WhatsApp, Telegram, Facebook, Twitter).

**Без этой картинки:** Ссылка выглядит как обычный текст
**С этой картинкой:** Красивая карточка с логотипом и информацией

---

## 📐 Требования

- **Размер:** 1200 x 630 пикселей (стандарт Open Graph)
- **Формат:** JPG или PNG
- **Размер файла:** до 5 MB (желательно до 1 MB)
- **Имя файла:** `og-image.jpg`
- **Путь:** `ClientAilin/public/og-image.jpg`

---

## 🎨 Рекомендуемая цветовая схема

### Основные цвета (из сайта):
- **Фон:** `#f8fafc` (светло-серый) или градиент
- **Акцент:** `#0d9488` (teal-700) - для логотипа и важных элементов
- **Текст заголовка:** `#1e293b` (темно-серый)
- **Текст описания:** `#64748b` (средне-серый)

### Градиент для фона (опционально):
```
from #f8fafc to #e0f2f1
```

## 🛠️ Способы создания

### Способ 1: Figma (Рекомендуется для дизайнеров)

1. Откройте Figma
2. Создайте новый Frame размером 1200x630
3. Добавьте фон
4. Добавьте текст и элементы
5. Export → JPG (Quality: 100%)

**Шаблон Figma:** [Можно найти в Community "OG Image Template"]

---

### Способ 2: Canva (Проще всего для начинающих)

1. Перейдите на https://www.canva.com
2. Создайте Custom Size: 1200 x 630 px
3. Выберите фон (светлый, можно градиент)
4. Добавьте текст:
   - Заголовок: **AylinDent** (жирный, большой)
   - Подзаголовок: Стоматология в Алматы
   - USP элементы
5. Добавьте иконки (можно из библиотеки Canva)
6. Download → JPG

---

### Способ 3: Photoshop

1. File → New → 1200x630px, 72 DPI, RGB
2. Создайте светлый фон (#f8fafc)
3. Добавьте текст и графику
4. File → Export → Save for Web (JPG, Quality: 80-90)

---

### Способ 4: Онлайн генератор OG Image

**Простой вариант:**
https://www.opengraph.xyz/

**Инструкции:**
1. Выберите шаблон
2. Введите текст
3. Настройте цвета (#0d9488 для акцента)
4. Download JPG

## ✅ Проверка работы

После создания og-image проверьте:

### 1. Локально
Откройте сайт, нажмите F12 → Elements → Найдите:
```html
<meta property="og:image" content="/og-image.jpg" />
```

### 2. В соцсетях
Поделитесь ссылкой на сайт в:

- Facebook

## ❓ FAQ

**Q: Можно использовать PNG вместо JPG?**
A: Да, но JPG обычно меньше по размеру. PNG используйте если нужна прозрачность (но для og:image прозрачность не нужна).

**Q: Что если картинка слишком большая?**
A: Сожмите через TinyJPG.com или уменьшите качество при экспорте до 80%.

**Q: Обязательно именно 1200x630?**
A: Желательно. Это стандарт. Минимум: 600x315, рекомендуется: 1200x630.

**Q: Нужно ли добавлять текст на казахском?**
A: Можно сделать две версии, но лучше использовать русский как основной для og:image.
